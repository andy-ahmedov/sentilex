# Эмоциональные кластеры и плотности NRC 2022: три профиля

## Ресурс и запуск

Исследовательская desktop-сборка автоматически анализирует тональность RuSentiLex и восемь эмоций NRC: **злость, грусть, радость, страх, удивление, ожидание, отвращение, доверие**. Они показаны в указанном порядке. Выберите UTF-8 `.txt`, задайте размер и нажмите «Анализировать». Словарь встроен в локальный exe; внешнего подключения и сети при работе не требуется.

Источник: [NRC EmoLex 0.92](https://saifmohammad.com/WebPages/NRC-Emotion-Lexicon.htm), Saif M. Mohammad, Peter D. Turney; National Research Council Canada. Английские метки получены вручную через краудсорсинг. **Русский перевод выполнен Google Translate в августе 2022 года; ручной русской разметки не заявлено.** Авторы отмечают улучшение относительно 2017, но сохраняющиеся ошибки и транслитерации.

В скачанной русской таблице 14154 строки. После отбора эмоциональных меток/русских переводов и объединения нормализованных записей — 3707 ключей. Строки без восьми эмоциональных меток, в том числе только positive/negative, маркерами не становятся. Эти две полярности NRC не заменяют RuSentiLex. Точные URL и SHA256 русского TXT, архива и README закреплены в [NRC2022.SOURCE.json](../scripts/data/NRC2022.SOURCE.json); [описание источника](../scripts/data/NRC2022.SOURCE.md) входит в сборку.

При запуске из исходников один раз выполните `.venv/bin/python tools/prepare_nrc2022.py` либо передайте `--archive /path/to/NRC-Emotion-Lexicon.zip`. Данные и README сохраняются локально в `scripts/data/nrc2022/`, игнорируются Git и Docker и включаются в собственный исследовательский exe. Передача данных или exe не входит в пользовательский сценарий. Windows-сборщик подготавливает отсутствующий ресурс автоматически. `openpyxl` и старый путь словаря в настройках не используются.

## Размер и поиск

После каждого выбора файла размер равен **1**. Ползунок предлагает 1…10, затем десятки и точный максимум. Числовое поле принимает любое целое 1…число предложений; введённые значения добавляются в ползунок. Оба элемента синхронизируются; до файла они отключены с минимумом 1 и неизвестным максимумом. Размер общий для тональности и эмоций. Шаг подписей глав меняет только подписи по порядку, не границы/метрики.

Слова словаря и текста приводятся к начальной форме; регистр и е/ё унифицируются. Совпадающие нормализованные переводы объединяют категории без повторения метки. Повторные вхождения считаются отдельно. Приоритет получает самое длинное словосочетание без перекрытий внутри предложения: один маркер с вкладом 1 в каждую его категорию. Трасса содержит исходное написание/символьные границы после предобработки, нормализованную форму и категории. Слова/счётчики фрагмента точно суммируются по предложениям.

## Плотности и категории

Для каждого предложения/фрагмента сохраняются число всех буквенных токенов `[^\W\d_]+`, восемь счётчиков и восемь плотностей:

`плотность категории = число её маркеров / число всех слов`.

В знаменатель входят слова без эмоциональных меток и все слова словосочетаний, но не числа/пунктуация. При нуле слов плотности нулевые. Плотность фрагмента — отношение суммарных маркеров к суммарным словам, не среднее плотностей предложений. Интерфейс/графики/TXT/HTML показывают плотность ×100, **маркеров на 100 слов**; CSV записывает само отношение с точкой (0.25 ↔ 25.00 на 100 слов).

Преобладают все категории с максимальной ненулевой плотностью до округления; равенства сохраняются. При нуле совпадений — «Эмоциональные слова не найдены», под предложением — «В этом предложении не найдены слова из словаря». Это не доказательство отсутствия эмоций. Нормализация позволяет сравнивать разную длину, но не меняет порядок категорий внутри фрагмента, поскольку знаменатель общий. Категории предложения и всего фрагмента могут различаться.

Отдельные **доли маркеров** нормированы по сумме восьми счётчиков; **доли текста** взвешены числом предложений с равным разделением между преобладающими категориями. Они не подменяют плотность, не равны эмоциональным фазам или web-распределению тональности по фиксированным порогам.

## Представление и файлы

«Эмоциональные кластеры» сохраняет тональную кривую, чёрное скользящее среднее с окном `2 × размер фрагмента + 1` и заливки от −1 до этой линии. При равенстве категорий — вертикальный градиент в порядке легенды. Матрица «Преобладающие эмоции по фрагментам» имеет восемь строк. Цвета: красный/синий/жёлтый/фиолетовый/бирюзовый/оранжевый/розовый/зелёный соответственно. Штриховка — нет маркеров. Высота заливки измеряет тональность, не силу эмоции.

«Плотность эмоций» — восемь ступенчатых кривых с постоянным значением внутри каждого фрагмента, X — номер предложения, Y — маркеров на 100 слов. Все границы фрагментов сохраняются. Для одновременного рассмотрения категорий используйте эти кривые: заливка выделяет только максимум.

«Маркеры кластеров» показывает текст после предобработки, выделенные вхождения и связи «Найдено: “боюсь” → страх». Начальные формы/счётчики/плотности находятся в подробностях. Автономный HTML экранирует пользовательский текст и открывается без сети. При смене файла, повторе и ошибке прежние просмотры/действия очищаются; при ошибке worker удаляет незавершённые файлы эмоций.

| Файл | Содержание |
|---|---|
| `*_emotions.png` | Градиенты и восьмистрочная матрица |
| `*_emotion_density.png` | Восемь плотностей на 100 слов |
| `*_emotions.csv` | Фрагмент, диапазон, предложения/слова, восемь счётчиков/плотностей, категории |
| `*_emotion_sentences.csv` | Фрагмент/предложение, текст, слова, счётчики/плотности, категории и маркеры; включая нулевые строки |
| `*_emotions.txt` | Сводка, источник и перевод, показатели фрагментов и основания меток предложений |
| `*_emotions.html` | Самостоятельный подробный экранированный отчёт |

CSV: UTF-8 BOM, `;`, десятичные отношения с точкой. Тональные TXT/PNG/PY, фазы и их расчёт не меняются; NRC в standalone PY не включается.

## Профили v2, v1 и исходный

По умолчанию выбран «NRC 2022 — правки для прозы (v2)». Сохранены прежний v1 и исходный перевод. После переключения выполните анализ заново: старые результаты очищаются; во время анализа выбор заблокирован. Raw содержит 3707 ключей, v1 — 3702, v2 — 3693.

v2 наследует семь решений v1 и добавляет 21 по английским размеченным значениям NRC: например, content → довольный, court → суд, pine → чахнуть, word → обещание. «Вдруг, внезапно» преобразовано в два отдельных соответствия. Суммарно девять исходных строк исключены, у 19 уточнены переводы; метки сохранённых строк не изменены. Полный журнал, первичные источники и отложенные случаи: [v2](lexicons/nrc_ru_literary_v2.md), [исторический v1](lexicons/nrc_ru_literary_v1.md). Правила: [v2](../scripts/data/NRC2022.LITERARY.v2.json), [неизменный v1](../scripts/data/NRC2022.LITERARY.json). Нет подгонки по частотам/интерпретации романа; широкий фильтр частей речи не используется, текст и знаменатель сохраняются.

TXT/HTML показывают id/полный SHA256, PNG — краткую подпись; в обоих CSV последние две колонки «Профиль словаря» и «SHA256 профиля» (формат не менялся). v2: nrc-ru-literary-v2, канонический JSON SHA256 `119bc130f86078a77053ddf1add6445cfd956e8ceac685fba0c2a9f95b311f6a`; v1: nrc-ru-literary-v1, прежний SHA256 `cbd2607a69f63549552956dd71ffb56f2ba99b76531646438499edae274a29e7`. V2 проверяет идентичность v1. Для raw id nrc-ru-2022-raw, SHA256 равен исходному ресурсу. Для воспроизведения прежних результатов выбирайте профиль явно и сверяйте отчёт.

## Известные ограничения

Ошибки/неоднозначности исходного машинного перевода остаются за пределами 28 выбранных записей. Коллизия нормализации «гора/горе» не устранена: текущий первый разбор может смешивать их метки; проверяйте исходное выделенное слово. Корректно переведённое слово также может иметь разные значения, а английская эмоциональная ассоциация — не переноситься на русский контекст. Словарь показывает ассоциации, не психологическое состояние автора или персонажей. Общие правила отрицаний, иронии и контекстного различения не добавлялись; существующие записи с отрицаниями по-прежнему сопоставляются как словосочетания. Отсутствие маркеров не доказывает отсутствие эмоций.

Профиль не выбирался так, чтобы какое-либо произведение стало грустнее. Сходство с литературной интерпретацией требует отдельной ручной оценки независимых отрывков. Автоматические проверки устанавливают реализацию, а не точность. «Кластеры» — фрагменты по категориям, не математическая кластеризация. Эмоциональные фазы — отдельная сегментация тональности относительно среднего, их типы не означают знак относительно нуля.

## Проверки

Из корня: `.venv/bin/python desktop/smoke_emotion_profile.py` и `.venv/bin/python desktop/smoke_emotion_profile_v2.py` (общие примеры, v2/v1/raw), smoke_emotions.py, smoke_emotion_fills.py, offscreen smoke_emotion_gui.py, smoke_chunk_slider.py и smoke_layout.py. Export/reanalysis выполняются последовательно; smoke_plot_options.py проверяет тональный график/экспорт; полный `make verify` включает golden. Windows `tools/smoke_frozen.ps1` (по умолчанию literary=v2; `-Profile literary_v1 -ReportName v2-v1` и `-Profile raw -ReportName v2-raw` для сравнения) тестирует `dist/SentiSoft-NRC2022-Literary-v2.exe` (или `-ExePath`) с запрещёнными исходящими Python socket-соединениями, реальными worker/UI, встроенным TXT/README/источником, восемью категориями и шестью файлами. Тональный TXT сравнивается с прежним golden после нормализации CRLF. Сборщик сохраняет открытые прежние exe.
