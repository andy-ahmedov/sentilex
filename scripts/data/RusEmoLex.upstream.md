# RusEmoLex - эмоциональный лексикон для русского языка

## Цитирование

При использовании ресурса RusEmoLex, пожалуйста, ссылайтесь на следующую публикацию:

```
Ярошенко П.В., Лукашевич Н.В. RusEmoLex: эмоциональный лексикон для русского языка // 
Russian Journal of Linguistics. 2025. Vol. 29. No 3. P. 659–687. 
https://doi.org/10.22363/2687-0088-44439
```

## Описание

Russian Emotion Lexicon (RusEmoLex) — это эмоциональный лексикон, созданный на базе объединения доступных русскоязычных источников:
- лексикографические ресурсы (словари и тезаурусы);
- корпусные данные;
- данные, полученные в результате опросов (зафиксированные ассоциации слов с эмоциями);
- наборы данных, используемые в машинном обучении.

## Методика создания

Создание RusEmoLex включает следующие этапы:
1. Формирование исходных списков эмоциональной лексики на основе доступных источников.
2. Объединение списков путем пересечения множеств слов из каждого отдельного источника.
3. Отбор лексики в RusEmoLex по критериям, представленным ниже.

## Критерии включения лексических единиц в RusEmoLex

Для включения в RusEmoLex лексическая единица должна удовлетворять следующим критериям:
1. Количество источников - лексическая единица должна входить в два или более источников.
2. Качество источников - как минимум один из источников должен относиться к словарным или корпусным ресурсам и не являться переводным.
3. Наличие метки класса - лексическая единица должна иметь установленный на основании большинства источников эмоциональный класс.

## Состав

RusEmoLex включает 1024 лексические единицы, размеченные по:
- частеречной принадлежности;
- эмоциональному классу;
- категории источников, где встречается слово (А - для источников высокой надежности, то есть лексикографических ресурсов и корпусных данных, В - для датасетов или переводных ресурсов, АВ - смешанный состав источников);
- количеству вхождений в источники.

# RusEmoLex - Russian Emotion Lexicon

## Citation

When using the RusEmoLex resource, please cite the following publication:

```
Iaroshenko,  Polina  V.  &  Natalia V.  Loukachevitch.  2025.  RusEmoLex:  Russian  Emotion  Lexicon.
Russian  Journal  of  Linguistics  29 (3).  659–687. https://doi.org/10.22363/2687-0088-44439
```

## Overview

Russian Emotion Lexicon (RusEmoLex) is an emotional lexicon constructed through the integration of various available Russian-language sources:
- lexicographic resources (dictionaries and thesauri);
- corpus data;
- word-emotion association lexicons;
- machine learning datasets.

## Development

The creation of RusEmoLex comprises the following stages:
1. Compiliation of initial emotional words lists from available sources.
2. Integration of lists through the intersection of word sets from all sources.
3. Selection of lexical items for RusEmoLex based on the criteria outlined below.

## Inclusion Criteria for RusEmoLex

For inclusion in RusEmoLex, a lexical unit must satisfy the following criteria:
1. Source frequency - the lexical unit must appear in two or more sources.
2. Source quality - at least one source must be a non-translated lexicographic or corpus resource.
3. Class designation - the lexical unit must possess an emotional class established by consensus across multiple sources.

## Content

RusEmoLex comprises 1,024 lexical units, annotated according to:
- PoS;
- emotional class label;
- source category attribution - A: high-reliability sources (lexicographic resources and corpus data); B: supplementary sources (datasets and translated resources); AB: mixed-source attribution)
- frequency of occurrence across sources.
