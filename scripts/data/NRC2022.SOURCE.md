# NRC EmoLex 2022 — локальная исследовательская сборка

Источник: [NRC Word–Emotion Association Lexicon](https://saifmohammad.com/WebPages/NRC-Emotion-Lexicon.htm), версия 0.92. Авторы: Saif M. Mohammad, Peter D. Turney; National Research Council Canada.

Английские метки получены ручной краудсорсинговой разметкой. Русский перевод выполнен **Google Translate, август 2022**, а не вручную. Авторы отмечают улучшение относительно 2017 года, но сохраняющиеся ошибки перевода и транслитерации. Записи не исправляются под ожидаемую интерпретацию произведения.

Загружается официальный `NRC-Emotion-Lexicon.zip`, член `NRC-Emotion-Lexicon/OneFilePerLanguage/Russian-NRC-EmoLex.txt`. Точные URL, SHA256 архива, русского файла и исходного README закреплены в [NRC2022.SOURCE.json](NRC2022.SOURCE.json). Контрольная сумма русского файла: `96849cb99a395e1e749030fa6c115860e2664f7690a1beac82c47485d42ce75a`.

В скачанной русской таблице **14154 строки** (без заголовка). Это не число уникальных эмоциональных русских лемм. После отбора восьми эмоциональных меток, русских переводов и объединения нормализованных ключей — **3707 ключей**. Нулевые метки и только positive/negative не создают эмоциональные маркеры. Порядок в Sentilex: злость, грусть, радость, страх, удивление, ожидание, отвращение, доверие. Совпадающие нормализованные переводы объединяют категории без повторения метки.

Публикация: Mohammad S.M., Turney P.D. Crowdsourcing a Word–Emotion Association Lexicon. Computational Intelligence. 2013. 29(3). 436–465. https://doi.org/10.1111/j.1467-8640.2012.00460.x

Пользовательская копия используется локально для некоммерческого исследования и демонстрации на конференции, без передачи словаря/сборки. Исходный русский TXT и README хранятся в игнорируемом `scripts/data/nrc2022/` и включаются только в локальный desktop exe. Данные не публикуются с исходниками и не попадают в web Docker image. Для получения своей копии: `.venv/bin/python tools/prepare_nrc2022.py`, либо `--archive /path/to/NRC-Emotion-Lexicon.zip`. При запуске программы сеть не используется. [Условия автора](https://saifmohammad.com/WebPages/NRC-Emotion-Lexicon.htm).
